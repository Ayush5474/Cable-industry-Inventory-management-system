# Cable-industry-Inventory-management-system
The Stock Monitoring System is designed to manage and monitor wire and cable inventory operations efficiently. The system helps users track materials, manufacturing, stock availability, customer orders, allocation, dispatch activities, and inventory movement through a centralized dashboard. 

The application provides: 

1.Real-time stock visibility  
2.Coil and inventory tracking  
3.Order management  
4.Dispatch monitoring  
5.Manufacturing tracking  
6.Reporting and analytics
